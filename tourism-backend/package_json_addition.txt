ADD this script to your package.json "scripts" section:

"save-models": "node src/scripts/saveModels.js"

So your scripts section becomes:
{
  "scripts": {
    "start":       "node server.js",
    "dev":         "nodemon server.js",
    "seed":        "node src/scripts/seedDatabase.js",
    "save-models": "node src/scripts/saveModels.js"
  }
}
